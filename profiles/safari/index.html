Safari deck

A 32-key Stream Deck XL layout for Safari 27. Every shortcut is read from Safari's own menu bar, so each key sends exactly what the menu item does. The keys borrow the Safari icon: dark glass tiles, a faint compass bezel, and a colour per row. Tap a key to see its menu path.
